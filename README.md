## 📌 About This Repository

Welcome to **Python Notes and Practice** — a learning repository created to organize Python programming concepts, examples, and practice exercises in one place.

This repository is intended for beginners who want to understand Python step by step, from their first program to more advanced concepts as the collection grows.

The notes and practice code are organized into chapter-wise folders to make learning easier, revision faster, and code simpler to find.

### 🎯 Objectives

- Build a strong foundation in Python programming.
- Understand concepts through small, executable programs.
- Practice syntax, operators, input/output, and other fundamentals.
- Keep notes and code organized chapter by chapter.
- Create a useful reference for revision and future projects.
- Track progress while learning programming.

> **Learning philosophy:** Don't just read the code. Run it, understand it, modify it, and try solving the problem yourself.

## ⚡ Getting Started

Follow these steps to run the programs on your computer.

### 1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

Verify your installation in the VS Code terminal:

```bash
python --version
```

On Windows, you can also try:

```bash
py --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/Sahil-XIED/Python-Notes-and-Practice.git
```

### 3. Open the Project

```bash
cd Python-Notes-and-Practice
code .
```

Alternatively, open the cloned folder using **File → Open Folder** in VS Code.

### 4. Run a Python Program

For example, to run the Hello World program:

```bash
python Chapter_1/1_helloworld.py
```

On Windows, if you use the Python launcher:

```bash
py Chapter_1/1_helloworld.py
```

You can run any other `.py` file by replacing the path with its filename.

## 💡 Example: Your First Python Program

print("Hello, World!")

## 🧠 How to Learn Effectively

1. **Understand:** Read the concept before running the program.
2. **Execute:** Run the code in your terminal.
3. **Experiment:** Change the values and observe the output.
4. **Practice:** Try solving a similar problem without looking at the solution.
5. **Revise:** Revisit older programs regularly.
6. **Document:** Add your own explanations and examples.

Consistency matters more than writing a large amount of code in a single day.
